# 90 kunlik no-production pilot rejasi

## Maqsad

Yoshlar-Ishi yordamchi navigator sifatida yosh foydalanuvchini to‘g‘ri rasmiy manba va keyingi qadamga yo‘naltirishini tekshirish. Davlat xizmatini ko‘rsatish yoki rasmiy murojaatlarni qabul qilish bu pilotga kirmaydi.

**Hudud:** Parkent tumani (taklif).  
**Davomiylik:** 90 kun.  
**Muhit:** no-production, ochiq kontent va sintetik test yozuvlari.  
**Maxfiylik:** dastlab real shaxsiy yoki davlat ma’lumotlari yig‘ilmaydi.

## Ish bosqichlari

| Davr | Ishlar | Natija |
|---|---|---|
| 1–2-hafta | Hamkor idora, biznes-egasi, yurist, IT va xavfsizlik mas’ullarini belgilash; ehtiyoj intervyusi | Scope, RACI, risklar va boshlang‘ich o‘lchov |
| 3–4-hafta | 10–15 xizmat/programmani rasmiy manbalardan idora bilan tekshirish | Kontent reyestri, owner, URL, sana, talablar |
| 5–6-hafta | Demo, sintetik data, anonim analytics, accessibility sinov | UAT ssenariysi va demo build |
| 7–10-hafta | Moderatsiyalangan foydalanuvchi sinovi | Task completion, referral accuracy, fikrlar |
| 11–12-hafta | Natijalarni tahlil, tuzatish, huquqiy/xavfsizlik review | Yakuniy hisobot va qaror loyihasi |
| 13-hafta | Go / revise / stop qarori | Pilot qabul bayonnomasi yoki qayta ishlash rejasi |

## KPI takliflari

Bu ko‘rsatkichlar pilot maqsadlari; normativ talab yoki kafolat emas.

| KPI | O‘lchash usuli | Taklif etiladigan maqsad |
|---|---|---|
| To‘g‘ri rasmiy manbaga yo‘naltirish | Idora tasdiqlagan javob kalitli task test | ≥ 90% |
| Keyingi qadamni tushunish | Testdan keyin foydalanuvchi qadamni qayta aytadi | ≥ 80% |
| Vazifani yakunlash | Yordamsiz task completion | ≥ 80% |
| Xizmat ma’lumotining yangiligi | Owner, manba va tekshiruv sanasi to‘ldirilgan kartalar | 100% |
| Kritik xavfsizlik kamchiligi | Mustaqil audit natijasi | 0 ta ochiq kritik topilma |
| Maxfiy ma’lumot hodisasi | Incident reyestri | 0 ta |
| Mobil qulaylik | 320–1440px va real qurilma sinovlari | P0 muammolar yopilgan |

## Sinov ishtirokchilari

- 16–17 yoshdagilar: faqat anonim/sintetik task test; voyaga yetmaganlar bo‘yicha huquqiy asos va qonuniy vakil tartibi oldindan ko‘riladi.
- 18–24 yoshdagilar.
- Texnikum/OTM o‘quvchilari va talabalari.
- Ish qidirayotgan yoshlar.
- Raqamli ko‘nikmasi past yoki accessibility ehtiyoji bo‘lgan foydalanuvchilar.

Real ism, telefon, pasport, JSHSHIR yoki murojaat nusxasi test uchun talab qilinmaydi.

## Go / no-go qabul mezonlari

1. Kontent egasi va har bir xizmat uchun mas’ul idora tasdiqlangan.
2. Foydalanuvchiga Yoshlar-Ishi mustaqil navigator ekani va rasmiy ariza yubormasligi aniq ko‘rsatilgan.
3. Xizmat manbalari idora tomonidan tekshirilgan, sana bilan qayd qilingan.
4. Accessibility va mobil sinovlarda bloklovchi muammolar qolmagan.
5. Real ma’lumot rejalashtirilsa: data controller/operator, qonuniy asos, hosting, transfer, retention, pentest, backup va incident response tasdiqlangan.
6. UZINFOCOM/tegishli operator talab qiladigan integratsiya yo‘li yozma kelishilgan.

Huquqiy yoki xavfsizlik sharti bajarilmasa, pilot ochiq ma’lumot va sintetik test darajasida qoladi yoki to‘xtatiladi.

## Pilotdan chiqadigan hujjatlar

- ehtiyoj va foydalanuvchi tadqiqoti;
- idora tasdiqlagan xizmat katalogi;
- task-based usability hisoboti;
- accessibility natijalari;
- xavfsizlik va privacy risk reyestri;
- texnik arxitektura/integratsiya spetsifikatsiyasi;
- KPI dashboard va yakuniy hisobot;
- kengaytirish/qayta ishlash/to‘xtatish qarori.
